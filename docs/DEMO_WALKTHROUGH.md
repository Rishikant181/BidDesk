# Demo walkthrough

1. Start the configured app with `npm run dev`; open `http://localhost:3000` and sign in.
2. Discover current notices, filter and preview results. Save an opportunity, select two to compare, or export the displayed page.
3. Open a tender and inspect normalized details and its official portal link. Source details are checked on opening/reload.
4. Save a company profile with supported financial/certification facts and a non-sensitive capability description. Select project evidence deliberately.
5. Run **Find tenders matching my profile**. Review the first 10 explained results, then scroll to load the next 10. The final batch may be smaller. Explain that the ranked shortlist is bounded to 30 and relevance is separate from eligibility.
6. In a tender, use **Analyze documents → Upload a PDF**, or **Documents → Set up the Firefox extension**. Attachments belong to that tender; no independent notice import exists.
7. Analyze chosen pages, inspect citations, select supported findings and confirm reviewed requirements. Review eligibility and optionally record a separate human evidence judgment.
8. Start preparing the bid, complete/save checklist tasks, label responsibility and set internal deadlines. Review the calendar and export the checklist.
9. Source changes observed during future retrieval create version history and private notifications. There is no background polling, official bid submission or award-results feed.

Use public/non-sensitive documents and capabilities with the demo AI configuration. The authenticated upstream Firefox download remains a manual smoke check; PDF upload works independently.
